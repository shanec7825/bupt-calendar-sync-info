BUPT Calendar Sync · Last updated: October 31, 2026

Purpose and data processed

BUPT Calendar Sync is a personal automation for copying timetable and homework information from the owner's BUPT services into Google Calendar and Google Tasks. It processes school account credentials and session data to access the school services; course names, times and locations; homework titles, due dates, descriptions and attachment names; and Google Calendar and Tasks data needed to locate and update synchronized items.

The requested Google Calendar and Google Tasks permissions can grant access beyond the calendars and task list currently targeted by the sync. The application reads calendar and task-list metadata, reads existing target events and tasks, and creates or updates synchronized events and tasks. The regular sync is designed not to delete items that disappear from the school source or reset a task's completion state.

Storage and service providers

The owner configures school and Google OAuth credentials as GitHub Actions repository secrets. GitHub Actions runs the synchronization and temporarily processes the school and Google data needed for each run. Google stores the events and tasks created in the owner's Google account. Separate course and homework export workflows, triggered manually or by changes to their workflow files, can store course and homework details, and accessible attachments, in private GitHub Actions artifacts configured for three days of retention. GitHub Actions log retention is governed by the repository's GitHub settings.

If the optional third-party OCR service is configured to solve a school login CAPTCHA, that service receives the CAPTCHA URL and temporary cookie needed to retrieve the image. Otherwise that optional service is not used.

Google and GitHub process data as providers of their respective services. The application is a personal project; it does not sell Google user data or use it for advertising. Its use and transfer of Google user data will comply with the Google API Services User Data Policy, including its Limited Use requirements.

Retention, removal and revocation

The owner's Google account retains synchronized events and tasks until the owner removes them or changes their account settings. Credentials remain in GitHub Actions repository secrets until removed or replaced. The owner can revoke the application's Google access through Google Account connections and disable the GitHub Actions workflow. Revoking access stops future authorized access but does not automatically delete previously synchronized events or tasks.
